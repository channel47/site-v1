The dry run wasn’t dry

2 manager accounts, 14 ad accounts, and about 12 offers

That was my new Google Ads setup after starting a new job. Bing looked similar, but Google was the powerhouse.

A few months earlier, I’d discovered this thing known as an API while trying to give a coding agent access to Drip, an email platform.

Drip exposed endpoints, little back doors that let an agent do the clicking for me. It could only do what Drip chose to expose, but it worked.

Now I had a wall of ad accounts running at different budgets and doing God knows what.

“Let me see what kind of API Google has.”

Turns out, a really good one.

Practically anything I could do in the UI, an agent could do through the API.

I built it without writing the code

An MCP is basically a wrapper that lets tools like Claude Code, Codex, and Cursor use an API.

When to use one instead of letting an agent hit the API directly is a question I’m not qualified to answer. Twitter is full of people who are.

I couldn’t find a reliable MCP server for Google Ads. To build one, you’d have to know Python and a whole bunch of other technical crap.

Or you could just have Claude do it.

That’s what I did.

I used Anthropic’s MCP Builder skill, pulled together OAuth credentials from Google Cloud and a developer token from the API Center in Google Ads, blindly followed the agent’s instructions, and somehow ended up with a working Google Ads MCP.

It had 13 tools for highly specific jobs. Pull search terms. Check campaign performance. That kind of thing.

Just loading those 13 tools consumed around 50,000 tokens before I’d sent a prompt.

The big AI labs have since fixed this, but at the time it was a real problem.

So I cut 13 specialists down to 3 generalists.

Those 3 tools could

  • list accounts
  • query almost anything available through GAQL
  • make changes to an ad account with mutate

I felt like a hacker. I love feeling like a hacker.

About a week after publishing it, I asked the MCP to validate a new ad without publishing it.

The server said

No changes were made.

I checked the account.

The ad was live.

The problem came down to two safety settings written in a format the connection to Google ignored. Nothing crashed. The guardrails simply never reached Google.

I wrote more about what broke and the guardrails I added here.
