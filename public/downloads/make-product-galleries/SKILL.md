# Make product galleries

Create product-gallery artwork that answers distinct buying questions in a coherent visual style. Adapt the process to the product, audience, and requested scope. Image production requires an available image-generation or editing tool; the brief and storyboard can be prepared without one. Say which parts were actually executed.

## Start from sources

Inspect the supplied product assets and label each input's role: authoritative appearance, factual source, style reference, or edit target. Follow explicit source replacements. A reference brand supplies visual and storytelling ideas, not product claims or packaging.

Collect only information that changes the work. Useful inputs include the product/variant, customer job, included contents, confirmed applications, instructions, purchase options, approved proof, and brand preferences. The blank `brief.md` is optional support for an incomplete brief.

Keep verified facts separate from assumptions. Creative defaults can fill gaps in palette or composition. They cannot establish dosage, wait times, compatibility, efficacy, pricing, fulfillment, certifications, or customer proof. If a consequential fact is missing, ask for it or omit the dependent statement. An instruction to assume defaults does not make the assumption verified.

## Plan the sequence

For a typical single product, propose 6–8 images unless the user specifies another count. Give each image a distinct customer question, a concise headline, source-backed supporting copy, and a visual composition. Adapt the sequence rather than filling mandatory slots.

A useful starting order is:

- Product identity and what arrives.
- Main benefit or authentic demonstration.
- Suitable applications.
- Verified preparation and use.
- Contents, refills, or ongoing ownership.
- Sourced customer proof, when available.
- Remaining purchase questions.

If the existing packshot is the hero, avoid immediately introducing the product again. For kits, clarify each item's role and shared contents. Do not fill an absent proof slot with invented reviews, generated before/after results, or repeated packaging claims.

## Establish and extend the visual direction

Generate one representative artwork using the actual product reference. Judge the hierarchy, palette, texture, spacing, and product fidelity before extending the set. Use the selected image as a style reference and retain the original product asset as the appearance reference for every subsequent image.

Vary layouts and background values to suit the information: a product composition, application windows, numbered steps, or a refill diagram. Maintain enough shared typography, color, and texture for the set to feel related. Keep headlines readable at mobile gallery width. Put essential details in accessible page text as well.

Give the image tool exact authored text and clear invariants. Generate the complete composition when that suits the direction; use source compositing or deterministic text rendering when exact packaging or type requires it. Do not claim pixel-exact product preservation without checking the result.

Request one finished artwork per output. Inspect actual returned dimensions rather than treating requested dimensions as delivered. Follow the available image tool's own instructions and preserve original outputs.

## Review images and the complete page

Compare each image with the sources. Check product identity, quantities, fine package text, authored copy, source-backed claims, margins, and mobile legibility. Make targeted revisions with explicit instructions about what must remain unchanged.

Then inspect the sequence alongside the product page, using a preview when available:

- Does each image answer a new question?
- Does the original hero make a generated introduction redundant?
- Do gallery instructions and offer details agree with verified product information?
- Can a shopper reach every image on mobile and desktop?
- Does image alt text describe its useful content?

A generated use scene illustrates a setting; it is not evidence of product performance. Attribute genuine customer proof to its source. Visual quality does not establish conversion lift.

## Deliver

Save the numbered artwork, exact prompts, source/assumption notes, and a simple gallery preview. Record which files and revisions were selected, actual dimensions, and remaining issues. Keep an earlier version when making a substantial revision.

Honor the user's scope and existing publishing authorization. Preparing images does not independently authorize changing a store, theme, offer, or published page. If installation is part of the request, back up the current media, preserve unrelated fields, and verify the rendered result.
